# Автосалон Renault

Веб-сайт автосалона Renault в городе Усть-Каменогорск. Многостраничный статический сайт с каталогом автомобилей и подробными характеристиками каждой модели.

## Структура сайта

Сайт состоит из 4 основных страниц и 6 страниц с характеристиками:

**Основные страницы:**
- **Главная** (`index.html`) -- hero-секция с фоновым изображением, приветственный блок и навигация
- **Автомобили** (`cars.html`) -- каталог с карточками автомобилей, фильтрация по типу кузова (внедорожник, седан, хэтчбек)
- **О нас** (`about.html`) -- информация о дилерском центре и его миссии
- **Контакты** (`contacts.html`) -- телефон, email, адрес и график работы

**Характеристики моделей:**
- Renault Kadjar -- внедорожник, от 8 400 000 тенге
- Renault Kaptur -- внедорожник, от 6 440 000 тенге
- Renault Talisman -- седан, от 9 240 000 тенге
- Renault Fluence GT2 -- седан, от 6 770 000 тенге
- Renault Clio -- хэтчбек, от 4 730 000 тенге
- Renault Megane -- хэтчбек, от 5 760 000 тенге

## Технологии

- HTML5, CSS3, JavaScript (vanilla)
- Адаптивная верстка: CSS Grid, Flexbox, `clamp()`, медиа-запросы
- Нет внешних зависимостей, фреймворков и сборщиков -- только чистые HTML/CSS/JS
- Тема: темная, фирменные цвета Renault (желтый `#EFDF00`, черный)

## Особенности

- Sticky-шапка с `backdrop-filter` и гамбургер-меню для мобильных устройств
- Hero-секция с фоновым изображением и полупрозрачным overlay (вместо тяжелого `text-shadow`)
- Карточки автомобилей с CSS Grid и hover-эффектами
- JavaScript-фильтр каталога по типу кузова
- Таблицы характеристик с подсветкой строки цены
- Полная адаптивность от 320px до широких мониторов

## Запуск

Откройте `index.html` в браузере или используйте локальный сервер:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```
