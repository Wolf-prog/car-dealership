# Автосалон Renault

Современный и быстрый веб-сайт автосалона Renault в городе Усть-Каменогорск.

Проект построен на чистом Vanilla JS (HTML5 + CSS3 + ES6) без сторонних фреймворков и сборщиков. Все данные о моделях вынесены в единый источник данных, а страницы генерируются динамически.

## Основные возможности и оптимизации

- **Единый источник данных (`data/cars.js`)**: все характеристики, цены, изображения и описания хранятся в одном месте. Добавление новой модели происходит за 1 минуту без дублирования верстки.
- **Динамический шаблон модели (`car.html?model=...`)**: вместо 6 одинаковых статических HTML-файлов используется одна легковесная страница-шаблон с получением параметров через `URLSearchParams`.
- **Живой поиск и фильтрация**: в каталоге (`cars.html`) доступен мгновенный поиск по названию/описанию и фильтр по типу кузова (внедорожник, седан, хэтчбек) на чистом JS.
- **Интерактивное модальное окно заявки**: по нажатию «Приобрести» открывается форма оформления заявки с валидацией без перезагрузки страницы.
- **Высокая производительность**:
  - Полностью устранены многослойные тяжёлые `text-shadow`, вызывавшие лаги и высокую загрузку GPU.
  - Оптимизированы фоновые изображения (используется затемняющий overlay вместо CSS-фильтров текста).
  - На изображениях каталога включена отложенная загрузка (`loading="lazy"`).
- **Адаптивность и мобильный UX**:
  - Адаптивное гамбургер-меню для экранов < 768px с автозакрытием при клике вне меню.
  - Автоматическая подсветка активного пункта навигации в шапке (`scripts/main.js`).
  - Верстка на CSS Grid и Flexbox с использованием функции `clamp()` для плавной адаптации шрифтов и отступов под любые разрешения.

## Структура файлов

```
car-dealership/
  index.html            Главная страница (Hero-блок с фоном)
  cars.html             Каталог автомобилей (поиск, фильтры, динамические карточки)
  car.html              Универсальная страница характеристик конкретной модели
  about.html            Страница «О нас»
  contacts.html         Контакты и график работы
  renault.ico           Favicon
  data/
    cars.js             Единый массив характеристик и моделей автомобилей
  scripts/
    main.js             Скрипт навигации (гамбургер-меню, активные ссылки)
  styles/
    styles.css          Базовые стили, сетка, адаптивность, тема Renault
    tables.css          Стили таблиц характеристик и модального окна
  images/               Изображения и логотипы
```

## Быстрый запуск

Сайт не требует сборки. Достаточно открыть `index.html` в браузере или запустить любой локальный статический сервер:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```
